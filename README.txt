خطوات بناء ملف APK:
1) ثبّتي برنامج Android Studio (مجاني) من developer.android.com/studio
2) افتحيه واختاري Open ثم اختاري مجلد AlHamdBeauty بعد فك الضغط
3) انتظري انتهاء Gradle Sync (يحتاج إنترنت أول مرة). وإذا سألك عن Gradle Wrapper فوافقي.
4) من القائمة: Build > Build Bundle(s) / APK(s) > Build APK(s)
5) الملف الناتج: app/build/outputs/apk/debug/app-debug.apk
6) انقلي الملف للهاتف وثبّتيه (فعّلي السماح بالتثبيت من مصادر غير معروفة).
لتغيير الأيقونة: Android Studio > File > New > Image Asset.
لتحديث البرنامج لاحقاً: استبدلي الملف app/src/main/assets/index.html ثم أعيدي البناء.
